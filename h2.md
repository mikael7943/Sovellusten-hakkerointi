# 1. OWASP top 10 0A1 broken access control
Pääsyoikeuksien hallinta valvoo käytäntöjä, että käyttäjät eivät voi toimia tarkoitettujen oikeuksiensa ulkopuolella. Alla lista yleisiä pääsyoikeuksien hallinnan haavoittuvuuksia:
  * Käyttäjällä on pääsy toimintoihin, joihin hänellä ei pitäisi olla oikeuksia.
  * Pääsynvalvontatarkistuksen ohittaminen muokkaamalla URL-osoitetta tai muita parametrien peukalointia.
  * Käyttöoikeuksien korottaminen. Toimiminen käyttäjänä ilman kirjautumista.
  * Metatiedon manipulointi, kuten JSON Web Token tai evästeen uudelleenkäyttö
  * Miten on mahdollista estää? Hyökkääjä ei voi muokata pääsynvalvontatarkistusta tai metatietoja.

# 2. Karvinen 2023 Find Hidden Web Directories - Fuzz URLs with ffuf
ffuf työkalun avulla voit etsiä piilotettuja hakemistoja:
  * ffuf kokeilee suuren määrän URL-osoitteita automaattisesti.
  * ffuf käyttää wordlistiä URL-osoitteiden automaattiseen syöttöön.
  * Tuloksia voi suodattaa esim. koon perusteella

# 3. Portswigger Access control vulnerabilities and privilege escalation
Pääsynhallinta tarkoittaa rajoitusten asettamista. Kuka tai mikä on oikeutettu suorittamaan toimintoja tai käyttämään resursseja.
  * Vertical privilege escalation, jos käyttäjä pääsee käsiksi toimintoihin, johon hänellä ei ole käyttöoikeutta. Esimerkiksi jos tavallinen käyttäjä pääsee hallintasivulle
  * Horizontal privilege escalation, jos käyttäjä pääsee käsiksi toisen käyttäjän resursseihin. 
  * Mikäli tavallinen käyttäjä vaihtaa URL-osoitetta voi hän päästä käsiksi esim. admin sivulle tai toisen käyttäjän tietoihin.
  * Miten estää? Estä pääsy oletusarvoisesti, testaa ja auditoi ja älä luota pelkkään hämärtämiseen.

# 4. Karvinen 2006 Raportin kirjoittaminen
Raportissa pitää ilmetä täsmällisesti mitä on tehty ja mitä sen jälkeen on tapahtunut.
  * Raportin pitää olla toistettavissa.
  * Täsmällinen, kerrottu tarkasti mitä komentoja on ajettu ja mitä sen jälkeen tapahtui.
  * Helppolukuinen, käytä väliotsikoita.
  * Lähteisiin viittaaminen.
