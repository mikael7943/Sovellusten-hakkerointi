## h4 Some Disassembly Required ##

# x) read/watch/listen/summarize #

* Ghidra on NSA:n kehittämä ohjelmistojen kääneismallinnus työkalu.
* Ghidran avulla voi tutkia ohjelman binääriä decompilerin avulla.
* Voit valita eri funktioita mitä tarkastella.
* Decompilerin avulla assemblyn voi muuttaa ymmärrettäväksi C-kieleksi, jota on helpompi tulkita.
* Videossa Ghidran avulla löydettiin heksadesimaali, joka käännettiin pythonin avulla oikeaksi salasanaksi.



# a) Install Ghidra #

* Aloitin lataamalla githubista ```https://github.com/NationalSecurityAgency/ghidra/releases``` Zip tiedoston virtuaalitietokoneelleni.
* Tämän jälkeen unzippasin sen
* Käytän Debiania, joten minun piti myös ladata jdk 25 komennolla ```sudo apt install openjdk-25-jdk```
* Käynnistin Ghidran komennolla /opt/ghidra/ghdiraRun
* Alkunäkymästä minulla ei nyt ole kuvankaappausta, mutta sain Ghidran toimimaan.

# f) Nora crackme02

* Aloitin tehtävän muokkaamalla crackme02 make komennolla ja importtasin sen ghidraan.

<img width="1201" height="598" alt="image" src="https://github.com/user-attachments/assets/a37f303c-9243-4fdc-ab16-c955e17d59dc" />

* Decompilerissa salasana "password1" esiintyy jälleen, mutta koodista päätellen se ei ole oikea salasana. Oletan oikean salasanan olevan jonkilainen ASCII muunnos password1:sestä.

* Ohjelman muuttujat:
  - param_1
  - param_2
  - cVar1
  - cVar2
  - uVar3
  - lVar4
 
* Muuttujien nimet ovat ghidran automaattisesti generoituja oletusnimiä
* Käydääs läpi mitä koodissa oikein tapahtuu ja saadaanko sen avulla selville oikea salasana ohjelmaan.

* Rivillä 10 tarkistetaan argumentti ```if (param_1 == 2)```. Ohjelma vaatii tasan yhden argumentin

* Rivit 11-12 ```cVar2 = 'p';``` Eli cVar alustetaan merkillä p. ```lVar4 = 0;``` laskuri alustetaan nollaan.

* Rivit 13-14 Tämä on merkki kerrallaan vertaileva tarkistus
  ```cVar1 = *(char *)(*(long *)(param_2 + 8) + lVar4);```
  
* Rivit 16-19 on avainkohta salasanan selvittämiseen. Käyttäjän syöttämän arvon pitää vastata arvoa cVar -1. Elikkä ASCII-arvo -1

```c
    if (cVar2 + -1 != (int)cVar1) {
        printf("No, %s is not correct.\n");
        return 1;
}
```

* Rivit 20-22 Silmukka päivittää vertailumerkin seuraavasta "password1"-kirjaimesta, kasvattaa ideksilaskuria ja jatkaa kunnes referenssimerkkijono loppuu.

```c
cVar2 = "password1"[lVar4 + 1];
lVar4 = lVar4 + 1;
} while (cVar2 != '\0');
```

* Nyt kun koodi on purettu auki voidaan ACSII taulukon avulla katsoa mikä salasana saadaan, kun miinustetaan 1 jokaisesta "password1" merkistä.

* Salasanaksi muodostuu o`rrvnqc0
