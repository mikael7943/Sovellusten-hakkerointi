# 1. main.cpp

* Aloitin tehtävän siirtämällä zip-tiedostot scp:n avulla virtuaalikoneeseeni.

* Tämän jälkeen asensin GNU debuggerin komennolla sudo apt install gdb.

* Käänsin koodin komennolla g++ main.cpp -g Wall -Werror -o main-dbg ja tämän jälkeen ajoin sen komennolla gdb ./main-dbg.
